### 3.1 FR-5.2 验收方法修订（P9 执行留痕）

原验收「iso 与 top 面板区域像素 diff = 0」前提不成立：程序化 HUD（无资产环境）为地形上的文字，无不透明底板，背景像素必然随投影不同。**修订**：改为捕获 HUD 字体调用（_RecordingFont），断言 iso 与 top 渲染文本序列逐条一致（= 面板/HUD 链路不经过投影模块，坐标语义不变）+ 目视无变形。资产面板路径（_panel 预合成，Wave V3）不透明，不受此影响。

## 4. 边界与负路径（tester 评审补充）
