## 2. 实体层：Unit 协议（鸭子类型）+ Vehicle/Turret

### 2.1 接口选型：Protocol（鸭子类型），不改 Mech 继承树

选型依据：Mech 已承载底盘/热量/驾驶员三套系统，继承重构（提基类）会触碰 M1-M7 全部构造路径，
违反「存量零破坏」前提；鸭子协议只做类型收敛，实体各自实现同名成员。

新增 `src/pymc2/domain/entities/unit.py`：`Unit` Protocol（structural typing，mypy 静态校验三方一致）：

- 可变状态属性：`id / faction / x / y / max_hull / weapon / move_target / fire_mode / guarding /
  attack_target_id / heat / pilot`
- 派生只读 property：`position / tile / alive / hull / hull_ratio / weapon_operational /`
  **`mobility_penalty / move_speed_px_s / mobile / sprite_kind`**（P2 新增四项，见 2.3）
- 方法：`tick(dt, *, move_speed_scale=1.0)` / `move_to(x, y)` / `apply_damage(location, amount) -> bool`

### 2.2 Vehicle（载具）：整体 HP + 无热量 + 可移动

MC2 语义映射：载具无部位伤害（整体 HP）、载具引擎无熔炉（武器不产热）、可移动。

- `hp` 整体血量：`apply_damage(location, amount)` **忽略 location**（签名气与 Unit 协议对齐，
  弹丸按部位结算路径复用不分支），直接扣减 hp；`alive = hp > 0`；`hull = hp`；`max_hull = 出厂 hp`。
- **无热量决策**：构造时强制 `weapon.heat_per_shot = 0.0`（dataclasses.replace 保留其余参数），
  HeatSystem 恒 0 → 无精度惩罚、永不 shutdown；不设「无热分支」，统一走存量 fire_at 路径
  （`add_heat(0)` 幂等）。
- 可移动：沿用 `move_target` 推进（与 Mech 同式），`VEHICLE_MOVE_SPEED_PX_S = 120.0`
  （快于机甲 96：轮式/悬浮机动优势）。
- `pilot = None`（弹道技能系数中性 1.0，M4 口径）；默认武器 `autocannon`（BALLISTIC）。
- 默认 hp=80（载具血量薄于机甲 100，MC2 同款口径）。

### 2.3 Turret（炮塔）：整体 HP + 不可移动 + 射程内自动开火

继承 `Vehicle` 骨架（整体 HP/无热量同款），覆写三处：

- `mobile = False`、`move_speed_px_s = 0.0`：`move_to` 为 no-op（永无移动意图），
  `BattleService.move_mech` 按协议 `mobile` 门槛拒绝（指令入日志、dispatch False 现有失败惯例）；
- `sprite_kind = "turret"`（vehicle 为 `"vehicle"`，Mech 为 `mech.id` 保持存量精灵链）；
- 自动开火**零新增代码**：`fire_mode` 缺省 FREE + battle_service `_auto_engage` 泛化后天然覆盖
  （射程 + LOS 过滤 + dispatcher 下发同一条路径）——守卫语义与机甲一致。
- 默认 hp=60。

### 2.4 Mech 增量（纯加法，四 property）

`mobility_penalty`（委托 `chassis.mobility_penalty`）/ `move_speed_px_s`（= 常量 MOVE_SPEED_PX_S）/
`mobile`（= True）/ `sprite_kind`（= self.id）。`Mech._advance_move` 不动（预测数学在 service 侧
改读协议字段，Mech 数值恒等 → 存量零差异）。

## 3. 武器三分类（BALLISTIC / ENERGY / MISSILE）

`Weapon` 增加 `wtype: WeaponType = WeaponType.BALLISTIC`（缺省 = 存量武器全部 BALLISTIC，零回归）。
三类弹道剖面（弹速 × 基础 `projectile_speed_px_s`，服务层注入口径不变）：

| 类型 | 弹速 | 伤害剖面 | 判定语义 |
| --- | --- | --- | --- |
| BALLISTIC | ×1.5（直射快弹） | `weapon.damage` 整发 | 命中部位按存量权重随机（roll_location） |
| ENERGY | ×1.0 | `weapon.damage` 整发 | **无视部位加成直伤**：跳过部位权重判定，恒 CT 直击（`location = MechLocation.CT`） |
| MISSILE | ×0.7 起步 + `MISSILE_ACCEL_PX_S2 = 240 px/s²` 末端加速 | **多发小伤齐射**：`MISSILE_VOLLEY_COUNT = 3` 发，`damage // 3` 均摊（余数记首发） | 齐射单次命中率判定（同一 will_hit），各发弹着点在目标周围 ±`MISSILE_VOLLEY_SPREAD_PX = 12` 散布 |

实现点：`Projectile` 增加 `wtype` 字段（缺省 BALLISTIC）；`advance()` 对 MISSILE 逐帧加速
（末端加速语义）；`fire_at` 按武器类型构造 1 发（BALLISTIC/ENERGY）或 3 发（MISSILE）投射物；
命中率/技能/热量精度惩罚三口径对三类型一视同仁（剖面只差异在弹速/弹数/部位语义）。

渲染分型（小改）：BALLISTIC 保持现有色圆点；ENERGY 青色圆点；MISSILE 橙色 4×4 方形弹体。

## 4. 服务层泛化（Unit 级）

以 `dict[str, Unit]`（字段名 `mechs` 保留——存量测试/调用零改动）承载全部单位：

- **battle_service**：全部方法注解 Mech → Unit；`_predicted_move_pos` 改读协议
  `move_speed_px_s / mobility_penalty`（Mech 数值恒等）；`move_mech` 增加 `mobile` 门槛
  （炮塔移动指令拒绝，机甲恒 True 零差异）；`fire_at` 武器三分类弹丸构造（BALLISTIC 缺省路径逐字节一致）；
  `_auto_engage/_engagement_target/_nearest_enemy_in_range/LOS/salvage` 逻辑零改动（协议成员已覆盖）。
- **AiCommander**：注解泛化；目标选择优先级规则（简单规则）：**攻击性目标（mobile）> 炮塔**——
  `_weakest_enemy` 排序键 `(not mobile, hull, dist, id)`；不可移动单位跳过 PRESERVE_FORCE 后撤
  与 SECURE_REGION 移动（fallback GUARD 原地死守，MOVE 指令本就会被 move_mech 拒绝）。
- **order_dispatcher**：零改动（指令接口按 id 路由，天然 Unit 无关）。
- **salvage_service**：`salvage_value` 接收 Unit（`hull/max_hull` 协议成员）；载具/炮塔整体 HP
  击毁即全损（hull=0）→ **击毁 salvage 折算 0 RP**（机甲残骸按部位余量折算 >0 的存量语义不变）。
- **refit_service.carryover_survivors**：`isinstance(mech, Mech)` 门槛——名册/整备闭环保持
  Mech-only；玩家侧 JSON/直构载具炮塔为战局内资产，不进名册（偏离记录 §8）。
- **trigger.py**：`spawn_reinforcement` 单元条目增加可选 `kind` 字段（`"mech"`(缺省容错)/
  `"vehicle"`/`"turret"`）；载具/炮塔条目复用 `hull/damage/range_px/cooldown_s` 参数键
  （`pilot_name` 仅 mech 消费）。条件/动作求值函数注解泛化（逻辑零改动）。

## 8. 偏离与裁剪清单

1. **战役链编制不动**：m2/m3 关卡保持全 mech（存量测试锁定编制），单位谱系经 m2b JSON + 直构
   战局交付；P3 .pak 官方任务布置接入时按 ObjectTypeNum 分派三类对象。
2. **炮塔精灵程序化回退**：官方作战炮塔仅 .ase 动画外观、无静态 TGA；`turret` stem 常量指向
   .ase 外观名占位，P4 .ase 波次接入动画后补官方外观。
3. **载具/炮塔击毁 salvage = 0 RP**：整体 HP 击毁即全损，无「部位余量残骸」可折算（机甲口径不变）。
4. **玩家侧载具/炮塔不入名册整备闭环**：carryover 按 `isinstance(Mech)` 门槛，战局内资产不跨关携带。
5. **载具无热量**经 `heat_per_shot=0` 归零实现而非删除 HeatSystem 成员：保持 Unit 协议单一路径，
   避免服务层新增无热分支。
6. **不做步兵**（远期池）；`take_damage` 遗留聚合口径不进 Unit 协议（仅 Mech 保留）。
