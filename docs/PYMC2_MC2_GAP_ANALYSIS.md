## §2 功能差距清单（P0-P3分级）

### P0（核心玩法必需）

#### 2.1 武器冷却独立周期 — ✅ 已实现（2026-11-25 DevSquad 评审核销）
- **实现证据**: mech.py L82-96（Weapon.cooldown_s/cd_remaining/can_fire 逐帧递减）+ battle_service.py L287（击发写入 CD）
- **原判定有误**: 「无单武器CD」与代码不符——单武器模型下独立 CD 已完整生效
- **残留**: 多武器多槽位 CD 随 2.4 装配编辑器落地（同一机制直接复用）

#### 2.2 官方tile-texture映射
- **现状**: 程序化哈希色块/确定性纹理池
- **目标**: .pak内tile索引→官方纹理ID映射
- **影响**: 视觉还原度低，无法复现原版地形
- **工作量**: 3人天
- **依赖**: PacketFile解析tile纹理索引 + MC2AssetPack扩展

#### 2.3 目标系统（Objective）
- **现状**: Trigger DSL + ScriptEngine 已有（胜负判定）；缺 Objective 三分类与 HUD 进度面板
- **目标**: Primary/Secondary/Bonus三分类 + 进度条
- **影响**: 任务目标不可见，玩家无导向
- **工作量**: 4人天
- **依赖**: MissionScript扩展 + HUD目标面板

#### 2.4 装配编辑器
- **现状**: 机甲配置硬编码（底盘工厂）
- **目标**: GUI拖拽武器/装甲 + 重量校验
- **影响**: 无战前定制，不符MC2核心循环
- **工作量**: 8人天（含UI布局）
- **依赖**: RefitService GUI前端 + 槽位约束逻辑

---

### P1（重要提升）

#### 2.5 斜投影改造（2.5D视角）
- **现状**: 纯顶视正交投影（0°俯视，无透视）
- **目标**: MC2固定斜视角透视（28-60° FOV + 透视缩放）
- **影响**: **架构级差距**，当前像棋盘，原版是3D场景；建筑只见屋顶 vs 可见立面/穹顶；地形平面感 vs 透视深度
- **工作量**: 6-8人天
- **依赖**: Renderer画面变换（y压缩−高度倾斜+按深度缩放）+ 点击拾取逆变换 + 命中/LOS换算 + 朝向帧按新投影角重渲染 + 面板遮挡
- **排序约束**: ⚠️ 必须在行走相位动画（2.7）之前，否则朝向帧返工
- **技术风险**: 高（触碰全部实体偏移/命中/LOS链路）

#### 2.6 顶点光照与阴影
- **现状**: 分级提亮（台阶亮度硬编码）
- **目标**: 8邻域法线平均 + 实时阴影投射
- **影响**: 地形缺乏立体感，昼夜无差异
- **工作量**: 5人天
- **依赖**: ElevationGrid法线预计算 + 光线投射

#### 2.7 行走动画（骨骼轨迹）
- **现状**: 8朝向静态帧（软件光栅单帧）
- **目标**: 780条CONTROL_TRACK骨骼动画
- **影响**: 机甲移动僵硬，缺乏重量感
- **工作量**: 10人天（.ase骨骼解析 + 插值）
- **依赖**: ASEParser扩展 + 动画状态机 + ⚠️ 2.5斜投影改造完成（否则朝向帧返工）

#### 2.8 战术地图（Minimap）
- **现状**: 无小地图
- **目标**: 实时敌我位置 + 目标点星标
- **影响**: 大地图迷路，战术决策困难
- **工作量**: 4人天
- **依赖**: HUD新增210×206px组件 + 单位追踪

#### 2.9 信息窗口（护甲图）
- **现状**: 无单位详情面板
- **目标**: 8部位护甲图 + 武器列表 + 滚动按钮
- **影响**: 无法查看单位状态，损伤不可见
- **工作量**: 5人天
- **依赖**: HUD新增208×208px组件 + 底盘状态视图

#### 2.10 ABL脚本引擎
- **现状**: Trigger DSL（5条件5动作）
- **目标**: IF/ELSE逻辑 + 全局变量 + 符号表
- **影响**: 任务逻辑受限，无法复现原版任务
- **工作量**: 12人天
- **依赖**: 字节码解释器 + SymTable + 回调接口

#### 2.11 驾驶员分配界面
- **现状**: 机甲-驾驶员隐式绑定（名册）
- **目标**: 技能卡片 + 头像 + 拖拽分配
- **影响**: 技能差异不可视，无分配决策
- **工作量**: 6人天
- **依赖**: RefitService GUI扩展 + Pilot显示逻辑

### P2（体验优化）

#### 2.12 水域tile动画
- **现状**: 静态纹理
- **目标**: 波浪动画（4帧循环）+ 透明度分层
- **影响**: 视觉单调，水域不明显

#### 2.13 散布未命中视觉反馈
- **现状**: ShotResult记录弹着点，无渲染
- **目标**: 弹着点地面标记（200ms淡出）
- **影响**: 未命中无反馈，观感不完整
- **工作量**: 1人天
- **依赖**: Renderer绘制弹着点粒子

#### 2.14 编队快捷键（Ctrl+1-9）
- **现状**: 框选 + Q托管
- **目标**: Ctrl+数字创建编队，数字召回
- **影响**: 多单位管理不便
- **工作量**: 3人天
- **依赖**: Game编队状态 + 快捷键绑定

#### 2.15 框选自动散开
- **现状**: 移动到同tile堆叠，错开逻辑简化

- **影响**: 堆叠触发让路超时逃生阀

- **依赖**: OrderDispatcher散开位置计算

#### 2.16 暂停指令模式
- **现状**: 实时下达指令

- **工作量**: 3人天
- **依赖**: Game暂停状态 + 指令缓冲队列

#### 2.17 热量条动画
- **现状**: 即时更新
- **目标**: 200ms平滑过渡 + 过热闪烁
- **影响**: 热量变化不直观
- **工作量**: 1人天
- **依赖**: Renderer插值逻辑

## §5 技术风险评估

### 高风险项（需PoC验证）

#### 5.1 斜投影改造（P1 / 6-8人天）
- **风险**: **架构级改造**，触碰全部实体偏移/命中/LOS链路，回归测试复杂
- **技术挑战**:
  1. 画面变换公式：`screen_y = world_y × 纵向压缩 − height × 倾斜分量 + 按深度缩放`
  2. 点击拾取逆变换（屏幕坐标 → 世界坐标）
  3. 命中判定/LOS 检测需按新投影换算距离
  4. 朝向帧按新投影角重渲染（P4 机甲帧需重做）
  5. 面板遮挡（底部UI 随地形透视调整）
- **缓解**:
  - 先用 2D 仿射变换（固定倾斜角 30°）做 MVP
  - 保留顶视模式开关（`--projection top/isometric`）
  - 建立像素级回归测试（对比 MC2 截图）
- **失败退路**: 维持顶视投影，只做光照优化（放弃 2.5D 还原）

#### 5.2 ABL脚本引擎（P1 / 12人天）
- **风险**: 官方字节码格式未完全逆向，IF/ELSE逻辑树复杂
- **缓解**: 
  - 先实现DSL→字节码编译器（绕过官方格式）
  - Trigger DSL扩展为准ABL（IF/变量/LOOP）
  - 保留原版.abl解析为Phase 5
- **失败退路**: 维持Trigger DSL，手工移植20个任务脚本

#### 5.3 骨骼动画插值（P1 / 10人天）
- **风险**: 780条CONTROL_TRACK插值计算量大，可能拖累帧率
- **缓解**:
  - PoC验证单机甲动画性能（目标≥30 FPS）
  - 预烘焙8朝向×10帧关键帧表（空间换时间）
  - 远距离LOD降级为静态帧
- **失败退路**: 维持8朝向静态帧，增加中间帧插值（伪动画）

#### 5.3 官方tile-texture映射（P0 / 3人天）
- **风险**: .pak内纹理索引格式不明确，可能缺字段
- **缓解**:
  - 参考MC2源码`Terrain.cpp`纹理映射表
  - 逆向单个.pak的tile-texture对应关系
  - 建立默认纹理映射表（官方缺失时回退）
- **失败退路**: 程序化纹理池（现状维持）

## §7 技术债务与现代化建议

### 7.1 架构层债务
| 技术债 | 影响 | 重构建议 |
|-------|------|---------|
| **pygame渲染单线程** | 物理/AI/渲染阻塞，帧率不稳 | 分离渲染线程（OpenGL后端） |
| **单例ObjectManager** | 测试困难，状态泄漏 | 依赖注入（BattleService构造传递） |
| **硬编码分辨率** | 1280×768写死，不支持高分屏 | 配置文件驱动 + UI自适应缩放 |

### 7.2 现代化升级路径（长期）
- **ECS架构**：替换Mech/Vehicle继承体系为组件组合（灵活性+性能）
- **Vulkan渲染**：硬件加速地形/动画（目标≥60 FPS @ 4K）
- **Lua脚本扩展**：ABL引擎基础上增加Lua API（社区Mod友好）
- **多人对战**：锁步同步（确定性模拟已具备）+ WebSocket通信
