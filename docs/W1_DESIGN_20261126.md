## §1. Task 1: Official Tile-Texture Mapping

### 1.1 Context & Problem

**Current State (V1.1)**:
- `renderer.py` renders terrain via procedural biome pools: `mc2_assets.ground_pool(terrain_kind)` → `Random_Maps/*.jpg` 4×4 grid-derived frames (see [V11_GROUND_POOL_DESIGN_20261121.md](V11_GROUND_POOL_DESIGN_20261121.md) §4).
- `mission_pak.py` only extracts `elevation` (f32@12) from packet 0 `PostcompVertex` (32B struct), ignoring `textureData`/`terrainType` fields.

**Goal**:
- Use official pak→texture index (`textureData` u32@16) to look up `Textures/64/*.tga` with triple-fallback:
  1. `texture_id` → Textures/64/ TGA (exact match)
  2. `texture_id` not found → `undefined.tga` (official fallback sprite)
  3. `undefined.tga` missing → JPG pool (V1.1 procedural, terrain_kind=grass/dirt/rock)

**Success Criteria**:
- Visual difference >50% when pak mapping enabled (mc2_01.pak rendering vs V1.1 JPG pool baseline)
- `undefined.tga` fallback path zero-crash
- Four gates green (ruff format/check + mypy + pytest 689 passed)

#### 1.2.2 `mc2_assets.py` Extension

**New API**:
```python
class MC2Assets:
    _texture_index: dict[int, Path]  # texture_id → Textures/64/*.tga path
    
    def ground_tile_by_index(
        self,
        texture_id: int,
        terrain_type: int,
        fallback_kind: str = "grass"
    ) -> pygame.Surface | None:
        """pak texture_id → Textures/64/ TGA（查表优先）→ JPG 池回退。
        
        Args:
            texture_id: pak packet 0 textureData 字段（u32）
            terrain_type: pak packet 0 terrainType 字段（u32，当前版本未消费）
            fallback_kind: JPG 池回退族（grass/dirt/rock/water/cement）
        
        Returns:
            纹理 Surface，优先 TGA；TGA 不存在时回退 ground_pool(fallback_kind)；
            ground_pool 返回空列表时返回 None（调用方兜底程序化色块）。
        
        Fallback Chain:
            1. texture_id in _texture_index → load TGA → force alpha=255 → scale to 64px
            2. texture_id not in _texture_index → load "undefined.tga" (stem="undefined")
            3. "undefined.tga" missing → ground_pool(fallback_kind)[0] (JPG pool first frame)
            4. ground_pool empty → None (renderer draws solid color tile)
        """
        # 查表逻辑：_texture_index[texture_id] → Path
        # Alpha 修正：64/ 系列 alpha 是高光通道（非透明度），强制置 255
        # 回退逻辑：undefined.tga → JPG 池首帧 → None
```

### 1.4 Risk Mitigation

#### 1.4.1 Risk: `textureData` Semantic Unknown

**Hypothesis**: `textureData` u32@16 是纹理索引 ID（直接映射 `Textures/64/{id}.tga`）。

**Validation**:
- Day 1 实测：加载 `mc2_01.pak`，统计 `textureData` 分布直方图
  - 预期非零率 >80%（Architect 设计假设）
  - 值域范围（如 10000-40000）匹配 `Textures/64/Detail_*.tga` 文件名
- 若分布为 UV 坐标打包（如 u16+u16）→ 需调整解析逻辑（W1 阻塞风险）

**Fallback**:
- 若 `textureData` 语义不明确 → W1 仅完成解析扩展，渲染回退 JPG 池（零破坏性）

#### 1.4.2 Risk: `terrainType` Enum Undocumented

**Current State**: MC2 Shared Source 未文档化 `terrainType` 枚举值。

**Strategy**:
- Day 1 实测 mc2_01.pak 分布（如 `{0: 1200 tiles, 1: 800 tiles, 2: 500 tiles}`）
- 逆向推断：0=草地（高频）、1=泥土、2=岩石、3=水面、4=水泥
- 建立 `_infer_fallback_kind()` 映射表

**Fallback**:
- 若 `terrainType` 值域异常 → 全回退 `fallback_kind="grass"`（零破坏性）

#### 1.4.3 Risk: `Textures/64/` Incomplete

**Official Asset**: `~/.pymc2/mc2-assets/Data/Textures/64/` 可能缺文件（用户稀疏 checkout）。

**Triple Fallback**:
1. `texture_id` → Textures/64/*.tga (exact match)
2. → `undefined.tga` (official fallback sprite，stem="undefined")
3. → `ground_pool(fallback_kind)` (V1.1 JPG pool)
4. → `None` → renderer draws solid color tile (程序化色块)

**Testing**:
- Day 3 集成测试：删除部分 TGA 文件，验证回退路径不崩溃

### 2.2 Data Structure Design

#### 2.2.1 `domain/scripting/objective.py` (New File)

```python
"""任务目标系统：三分类目标（PRIMARY/SECONDARY/BONUS）+ 胜负判定。"""

from __future__ import annotations

from dataclasses import dataclass
from enum import Enum

@dataclass(frozen=True)
class ObjectiveType(str, Enum):
    """目标类型三分类。"""
    PRIMARY = "primary"      # 主要目标（全部完成 → 胜利）
    SECONDARY = "secondary"  # 次要目标（可选）
    BONUS = "bonus"          # 奖励目标（隐藏/可选）

@dataclass(frozen=True)
class ObjectiveStatus(str, Enum):
    """目标状态（单向状态机）。"""
    PENDING = "pending"      # 未完成
    COMPLETED = "completed"  # 已完成
    FAILED = "failed"        # 失败

@dataclass
class Objective:
    """单个目标（可变状态）。
    
    状态机：PENDING → COMPLETED/FAILED（单向，不可逆）
    """
    id: str                     # 目标唯一 ID（JSON 中指定）
    type: ObjectiveType         # 目标类型（PRIMARY/SECONDARY/BONUS）
    description: str            # 显示文本（HUD 面板）
    status: ObjectiveStatus = ObjectiveStatus.PENDING  # 当前状态

@dataclass
class ObjectiveSet:
    """任务目标集合（内置胜负判定逻辑）。"""
    objectives: list[Objective]
    
    def all_primary_completed(self) -> bool:
        """所有主要目标完成 → 胜利条件。"""
        return all(
            obj.status == ObjectiveStatus.COMPLETED
            for obj in self.objectives
            if obj.type == ObjectiveType.PRIMARY
        )
    
    def any_primary_failed(self) -> bool:
        """任何主要目标失败 → 失败条件。"""
        return any(
            obj.status == ObjectiveStatus.FAILED
            for obj in self.objectives
            if obj.type == ObjectiveType.PRIMARY
        )
    
    def by_id(self, obj_id: str) -> Objective | None:
        """按 ID 查找目标。"""
        return next((obj for obj in self.objectives if obj.id == obj_id), None)
```

**MissionScript Extension**:

```python
@dataclass
class MissionScript:
    """任务脚本（扩展 objectives 字段）。"""
    triggers: list[TriggerDef]
    objectives: ObjectiveSet | None = None  # 新增：目标集合（可选）

def load_mission_script(path: Path) -> MissionScript:
    """JSON → MissionScript（扩展 objectives 段落解析）。"""
    data = json.loads(path.read_text(encoding="utf-8"))
    triggers = [_parse_trigger(t) for t in data.get("triggers", [])]
    objectives = _parse_objectives(data) if "objectives" in data else None
    return MissionScript(triggers=triggers, objectives=objectives)

def _parse_objectives(data: dict[str, Any]) -> ObjectiveSet:
    """JSON objectives 段落 → ObjectiveSet。
    
    JSON 格式：
    {
      "objectives": [
        {"id": "obj1", "type": "primary", "description": "Destroy enemy base"},
        {"id": "obj2", "type": "secondary", "description": "Capture resource point"}
      ]
    }
    """
    raw_objs = data.get("objectives", [])
    return ObjectiveSet(objectives=[
        Objective(
            id=obj["id"],
            type=ObjectiveType(obj["type"]),  # Enum 严格校验（ValueError 若非法值）
            description=obj["description"]
        )
        for obj in raw_objs
    ])
```

**ScriptEngine Extension**:
```python
class ScriptEngine:
    """任务脚本引擎（扩展 _update_objectives tick 方法）。"""
    
    def tick(self, mission: Mission, dt: float) -> None:
        """每帧更新：Trigger 评估 + 目标更新 + 胜负判定。"""
        self._evaluate_triggers(mission, dt)
        self._update_objectives(mission)  # 新增
    
    def _update_objectives(self, mission: Mission) -> None:
        """每 tick 更新目标状态 + 自动胜负判定。"""
        if mission.script.objectives is None:
            return
        
        # 更新目标状态（Trigger 完成 → Objective 完成）
        for obj in mission.script.objectives.objectives:
            if obj.status == ObjectiveStatus.PENDING:
                # 检查目标条件（调用 Trigger 条件评估逻辑）
                if self._check_objective_condition(obj, mission):
                    obj.status = ObjectiveStatus.COMPLETED
        
        # 胜负判定
        if mission.script.objectives.all_primary_completed():
            mission.victory = True
        if mission.script.objectives.any_primary_failed():
            mission.defeat = True
    
    def _check_objective_condition(self, obj: Objective, mission: Mission) -> bool:
        """检查目标完成条件（W1 简化：关联 Trigger ID）。
        
        W1 实现：obj.id 匹配同名 Trigger ID，Trigger 触发 → Objective 完成。
        W2+：支持复杂条件（AND/OR 组合、计数器阈值等）。
        """
        # 简化实现：obj.id = trigger_id，查找同名 Trigger 是否已触发
        for trigger in mission.script.triggers:
            if trigger.id == obj.id and self._is_trigger_fired(trigger, mission):
                return True
        return False
```

```python
                    )

                        surface, checkbox_color,
                        (checkbox_x + 10, checkbox_y + 2),

                # PENDING: 白色空框（无内部符号）
```
