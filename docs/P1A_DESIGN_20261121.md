- 日期：2026-11-21
- 性质：P1 主线第一切片设计（P1-B 视线遮挡不在本切片）
- 输入：docs/MC2_PLAN_20261121.md §2（P1 高程）、docs/ASSESSMENT_MC2_STYLE_20261120.md §1（地形高程差距）
- 硬约束：默认 flat 下 458 个存量测试行为输出逐字节不变；四项门禁全绿；MC2 资产零入库

## 1. 数据模型（src/pymc2/domain/elevation.py，新文件）

`ElevationGrid`：40×40 per-tile int 高程网格。

- 高程取值 0..`ELEVATION_MAX=3`，构造时钳制存取；地图外 tile 一律视为 0（平面延伸）。
- 构造三来源：
  1. **全零平面**：`ElevationGrid()` / `ElevationGrid.flat()`——默认战局；
  2. **显式行数组**：`ElevationGrid(rows)`，形状必须 40×40（ValueError），值钳制到 0..3；
  3. **确定性丘陵**：`generate_hills(seed=HILLS_SEED)`。
- 查询 API：
  - `elevation_at(tile) -> int`：越界返回 0；
  - `climb_allowed(from_tile, to_tile) -> bool`：`elevation_at(to) - elevation_at(from) <= CLIMB_MAX_DELTA(=1)`
    ——下坡/平地不限，高出 1 级以上不可爬。相邻 tile 为定义口径；非相邻（MOVE_TO 端点直判）
    沿用同一公式（无寻路简化，见 §3）；
  - `is_flat() -> bool`：O(1) 快路径（构造时预计算 max），flat 网格下移动/渲染全走存量分支。

### 确定性丘陵生成（generate_hills）

风格对齐 renderer 装饰撒点（`_grass_color`/`plan_decorations` 的 md5 确定性哈希）：

- **value noise**：粗网格边长 `_HILLS_LATTICE_CELL=8` tile，角点高度 =
  `md5("pymc2-hills:{seed}:{ix}:{iy}")[0] % 4`，tile 高度取四角双线性插值后四舍五入——
  相邻 tile 高差天然 ≤1 为主、成片成坡，避免撒盐噪声；
- **保护区归零**（保证默认战局走廊可用）：
  - 道路 tile（row 10 / col 25，与 renderer `_ROAD_ROW`/`_ROAD_COL` 同值，渲染层私有常量
    不上提，elevation.py 以 `ROAD_TILE_ROW/COL` 重复声明并注释对齐）；
  - 出生保护区：全模式出生 tile 汇总（玩家 6/8/10 列 ×row10 + 敌方 18/20/24 列 ×row10 +
    侧翼 (20,13)/(22,13)/(26,8)/(26,12)）的 Chebyshev 半径 2 邻域；
- seed 默认 `HILLS_SEED=20261121`，同 seed 同网格（e2e 可按确定性检索特定高程 tile）。

## 2. 移动代价与爬升限制（battle_service）

- `BattleService.__init__` 新增可选 `elevation: ElevationGrid | None = None`，缺省挂全零平面
  ——service 恒持有网格，flat 快路径下移动数学与存量完全一致；
- **步进耗时加成**：`_climb_multiplier(mech, target, dt)`——以基础速度预测本帧将进入的 tile
  （与 `Mech._advance_move` 同式抽公共 `_predicted_move_pos`），Δ=elev(进入)-elev(当前) > 0 时
  该帧步长 ×`CLIMB_COST_PER_LEVEL^Δ`（每 +1 级 ×1.5，Δ=2 → ×2.25 复利）；Δ≤0（平地/下坡）
  ×1.0（下坡不加速）；tile 内移动不加成。`Mech.tick` 增关键字参数
  `move_speed_scale: float = 1.0`（默认不变，实体无高程依赖）；让路快照预测
  `_frame_next_tile` 同步乘同一系数（移动物理两处口径一致，防让路相位漂移）；
- **爬升限制**（无寻路简化）：`move_mech` 增 `_climb_permitted` 校验——目标 tile 高于当前
  tile 超过 `CLIMB_MAX_DELTA` → 拒绝（返回 False，`move_target` 不落）。回执按现有 dispatcher
  失败处理惯例：指令仍入 `order_log`、`dispatch` 返回 False，不新增 REJECT 条目类型；
- **让路协商语义不变**：高程不参与占位/互换判定（静态占位、互换对冲公式原样），
  仅移动物理速度带高程系数。

## 3. terrace 渲染（renderer）

- `Renderer.__init__` 新增可选 `elevation` 参数（`create_game` 从 `service.elevation` 注入；
  渲染层单一数据源，`render()` 不改签名，内部统一读 `self._elevation`）；
- **terrace 版面**：flat/未注入 → `_build_terrain()` 原路径逐字节不变（`_terrain_y_offset=0`）；
  含丘陵 → `_terraced_terrain_surface(base)`：
  - 版面加高顶部 `ELEVATION_MAX*ELEVATION_STEP_PX=30px` 防裁切，底图整体下移 30px；
  - 逐 tile 行序（自北向南）覆盖绘制：顶面 = 原 tile 纹理区上移 `e*ELEVATION_STEP_PX(=10px)`
    （行序保证高层顶面正确压住北邻低层底边，画法求算法家式遮挡）；
  - 南邻更低时画**深色崖壁**（`_CLIFF_COLOR`，深棕）：恰好填补「本 tile 顶面下缘 ↔ 南邻
    顶面上缘」的高差条带（高度 = 高差×10px，两端精确衔接无重叠）；地图南缘越界视为 0 →
    边缘崖壁；
  - 北/东/西侧高差在本投影（纯 Y 偏移）下为零宽接缝，不单独画侧面（见 §5 裁剪）；
- **实体高程偏移**：机甲/装饰/弹丸/移动标记/攻击高亮按所在 tile 高程同步上移
  `e*10px`（血条/标签随锚点联动）；**y 排序键改 `(elevation, y)`**（先高程后 y，
  避免高层机甲被低层前景遮挡错序；flat 退化为纯 y 排序，存量次序不变）；
- **V3 底部面板**：blit 序保持最后（最上层），不受偏移影响（现状已满足，仅回归保障）；
- **HUD**：状态行选中机甲时追加 ` | ELEV: n`（ASCII，收进现有 `FIRE:/SEL:/HEAT:` 尾部惯例；
  未选中不追加——面板模式走 dropteam 槽原样，不加 ELEV）。

## 4. 开关与任务脚本覆盖

- **CLI**：`--terrain {flat,hills}`（默认 flat）。main 在 `chain.start_mission` 之后、
  `create_game` 之前把 `generate_hills()` 赋给 `battle.elevation`（Renderer 经 create_game 注入）；
- **任务脚本可选覆盖**：`MissionScript` 增 `elevation: ElevationGrid | None = None` 字段，
  JSON 顶层可选 `"elevation"` 键：`"hills"` 关键字 → `generate_hills()`；显式 40×40 行数组 →
  直接构造。加载容错：缺失/非法（类型错误、形状错误、未知关键字）→ `None`（不覆盖，
  等效全零默认；不抛 MissionScriptError，不阻断任务加载）。main 按「CLI 先挂、脚本覆盖后挂」
  顺序接线（脚本显式声明优先于 CLI）。

## 5. 偏离与裁剪

1. **非相邻 climb_allowed 沿用同一公式**（任务口径「相邻 |Δ|≤1，非相邻不适用」）：MOVE_TO
   端点直判需要非相邻取值，取同一 Δ≤1 公式最简一致；
2. **无寻路**：爬升限制只判指令端点，直线路径中段若穿越 +2 崖（发送时端点合法）不拦截
   （P1-A 裁剪，MC2 原版有寻路绕行；后续切片再评估）；
3. **只画南侧崖壁**：纯 Y 偏移投影下北/东/西侧面为零宽，画了不可见；高程台阶以纹理接缝呈现；
4. **elevation 键缺失/非法 → 不覆盖**（等效全零）而非强制清零：保证 CLI `--terrain hills`
   不被无 elevation 键的任务脚本清零（否则开关失效）；非法键静默容错不报错；
5. **装饰不参与高程遮挡排序**：装饰仍画在机甲之下（现序），丘陵 tile 上的装饰随 tile 上移，
   但被南侧更高顶面遮挡的极端构图不处理（纯装饰，可接受）；
6. **框选矩形不随高程偏移**：屏幕空间直线语义，任务清单未列；
7. **跨帧加成的帧率近似**：进入 tile 的那一帧整帧乘系数（不按跨界比例折算），60fps 下
   误差 <1px/帧，换取 O(1) 判定与两处口径一致。
